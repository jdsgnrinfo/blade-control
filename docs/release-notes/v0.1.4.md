Battery life: Blade Control itself no longer wastes power.

- **The Performance page no longer keeps the NVIDIA GPU awake.** Its system monitor asked NVIDIA's driver library for the GPU's load every second, so once anything woke the GPU, the monitor held it awake for good, with Windows' System process busy on about a whole core. The library is now asked only while another app is using the GPU and let go when none is.
- **Fewer sensor reads on battery**: the device panel reads every 5 seconds instead of every second, the system monitor every 3, the Battery page every 5, the Display page's GPU line every 10, the app profiles' watch every 5 and Silent's checks every 10. Plugged in, nothing changes. With the Performance page open on battery, the app went from about 15% of a core to 4.5%.
- **System monitor switch**: Settings, General turns the Performance page's system monitor off; its card goes and nothing is read for it.

Download `BladeControl-v0.1.4-win-x64.zip`, unzip it into a folder of its own (replacing the old files) and open `BladeControl.exe`. Your settings are kept.

Autonomía: Blade Control ya no gasta batería por su cuenta.

- **La página Rendimiento ya no mantiene despierta la GPU NVIDIA.** Su monitor del sistema preguntaba cada segundo a la biblioteca del driver de NVIDIA por la carga de la GPU, así que, en cuanto algo la despertaba, el monitor la mantenía despierta para siempre, con el proceso System de Windows ocupando casi un núcleo entero. Ahora solo se le pregunta mientras otra app usa la GPU, y se suelta en cuanto ninguna la usa.
- **Menos lecturas de sensores con batería**: el panel del portátil lee cada 5 segundos en vez de cada segundo, el monitor del sistema cada 3, la página Batería cada 5, la línea de la GPU de la página Pantalla cada 10, la vigilancia de los perfiles de app cada 5 y las comprobaciones de Silencio cada 10. Enchufado no cambia nada. Con la página Rendimiento abierta y con batería, la app pasó de usar un 15 % de un núcleo a un 4,5 %.
- **Interruptor del monitor del sistema**: en Ajustes, General, se puede apagar el monitor del sistema de la página Rendimiento; su tarjeta desaparece y no se lee nada para él.

Descarga `BladeControl-v0.1.4-win-x64.zip`, descomprímelo en su propia carpeta (sustituyendo los archivos anteriores) y abre `BladeControl.exe`. Tus ajustes se conservan.
